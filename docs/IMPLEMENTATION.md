## Evidence levels

1. **Local fixture tests:** real Git repositories, Python child processes,
   SQLite restarts, deterministic policy execution, behavioral grading, actual
   cancellation and Windows Job Object cleanup. Model calls are mocked.
2. **OS sandbox:** opt-in real-boundary tests and a Linux CI job are provided.
   This Windows host rejects restricted reads with its current backend.
   A successful target-platform sandbox run remains necessary.
3. **Live model:** no live OAuth inference was performed during implementation.
   The installed CLI reports a saved ChatGPT login. This does not establish an
   available model, successful inference or current remaining allowance.
4. **Pi deployment:** not performed. Neither ARM64 execution nor the service
   units have been verified on the user's Ubuntu 24.04 Pi.
5. **Useful improvement:** the supplied lexical example improves the deliberately
   simple seed on synthetic public smoke cases. This establishes the mechanism,
   not independent task generalization, memory benefit or research novelty.

## Experimental boundaries

The 18 supplied cases are public synthetic fixtures: 12 development and 6
selection. The handoff's proposed 80 independently labelled tasks must still be
collected from authorized real material. No generated fixture count is presented
as that independent dataset. Final audit labels must be independently provisioned
and kept outside the proposing worker's readable filesystem and runtime roots.

Behavior is scored by trusted code from actual selected evidence. A candidate
cannot edit the supervisor/evaluator, regression tests, configuration, or task
splits through the experiment path. Strict profile restrictions must work on the
target machine; read-only placement alone would not hide final-audit answers.

Meta experiments compare 1–3 matched trials, alternate order, disable retrieved
memory, and retain the same initial parent and active policy. Descendant versions
are archived but not activated during a comparison. The mutation proposal's cost
is included when it was generated by RSI. Unknown usage or changing observed
model/CLI metadata blocks a positive comparison. These small experiments are
exploratory and carry no causal/statistical significance claim.

experiment steps. It is not claimed from mocked inference or synthetic fixtures.
